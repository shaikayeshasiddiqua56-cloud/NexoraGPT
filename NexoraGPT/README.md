# NexoraGPT
An individual chatbot project developed using HTML, CSS and JavaScript.

## About the Project
NexoraGPT is my individual project. It is a simple chatbot website developed using HTML, CSS and JavaScript.

It allows users to send messages and receive predefined responses.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- New Chat
- Recent Chats
- Chatbot Replies
- Voice Input
- Dark Mode
- Language Selection
- My Profile

## How It Works
The chatbot checks keywords in the user's message and gives predefined responses using JavaScript conditions.

Voice input converts the user's speech into text.
